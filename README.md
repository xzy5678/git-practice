# git-practice

这是我学习 Git 和 GitHub 时创建的第一个仓库。

## 目的

- 走通 `git init` → `add` → `commit` → `log` → `push` 的完整流程
- 理解四个区域：工作区、暂存区、本地仓库、远程仓库
- 学会用 `.gitignore` 排除不该提交的文件

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `hello.py` | 一个可以随便改的小脚本，用来产生"改动" |
| `.gitignore` | 声明哪些文件不提交到 Git |
| `README.md` | 就是你现在看的这个文件 |
